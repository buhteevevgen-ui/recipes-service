# Бэклог фичей

Список того, что можно добавить на сайт. Откуда взята каждая идея, описано в [REFERENCES.md](REFERENCES.md).

Обозначения:
- **Приоритет**: P1 — делаем следующим, P2 — потом, P3 — когда-нибудь или если понадобится.
- **Размер**: S — до часа, M — вечер, L — несколько заходов.

## Уже сделано

- Каталог в `recipes.json`, сайт на GitHub Pages, консольная версия `recipes.py`.
- Нечёткий поиск по названию, тегам, ингредиентам и шагам.
- Разделы: «На каждый день», «Гриль», «Смокер», «На компанию».
- Адаптивная вёрстка для телефона.
- Убрано облако тегов: фильтры тегов на списке и кнопки тегов на странице рецепта удалены; теги остаются в данных и в поиске (T-7, PR #16).
- Варианты замены в заметках (например, сливки или молоко с маслом в орзо).

## Черновик полей для рецептов гриля и смокера

```json
{
  "bbq": {
    "method": "smoke",
    "pitTemp": { "c": 110, "f": 225 },
    "targetTemp": { "c": 95, "f": 203 },
    "wood": ["вишня", "дуб"],
    "setup": "две зоны",
    "rest": "1–2 часа в термобоксе",
    "yield": 0.57
  }
}
```

`yield` — доля веса после готовки. Её использует калькулятор порций.

## Как пользоваться бэклогом

- Новая идея → добавляем строку в нужный блок.
- Перед началом работы над пунктом проверяем референс в [REFERENCES.md](REFERENCES.md).
- Сделанное переносим в «Уже сделано».
